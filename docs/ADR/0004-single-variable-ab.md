# ADR-0004：A/B 实验必须单变量，且同时报告代价

- 状态：已接受（2026-11-26）
- 背景：三个机制（切片推理、时序投票、告警去重）互相影响；如果一次打开
  全部开关再说「效果变好了」，无法归因，也无法解释代价。
- 决策：
  - 每个实验只改 `variable` 指明的一个开关，其余全部冻结并写入
    `frozen_conditions`（权重、图片列表、顺序、seed、imgsz、IoU、设备）；
  - 两组都报告 **Precision / Recall / F1（greedy IoU@0.5）+ 延迟 + 检测框数
    + 告警事件数**，禁止只报有利指标；
  - 每个 JSON 都带 `conclusion_boundary`，说明该结论不能被外推到哪里；
  - 置信度阈值另设一组实验（E2），因为它不是结构改动而是判定门槛；
  - **允许负结果**：某开关在本数据分布上若无收益，报告照实写，并把默认值
    设为关闭（E1 切片即如此，`configs/inference/default.yaml` 中
    `enable_tiling: false`）。
- 理由：可归因的对照是「价值」成立的前提；同时测代价能防止把「检出框变多」
  误当成「准确率提升」。用错误输入去测一个机制，得到的 0 分不是该机制的
  结论，而是实验设计的缺陷 —— 这正是 E3 被重新设计的原因。
- 后果：
  - **E3 采用受控扰动实验**：每张真实图片只推理一次，再按固定 seed 构造
    5 帧片段（每帧丢弃 30% 的**真实检出框**，模拟瞬时漏检），两臂看到完全
    相同的片段、唯一差异是投票开关。注入参数写入
    `frozen_conditions.temporal_probe`；报告仍明确写出「不是真实连续视频」。
  - E4 在本批 100 张图上事件数未变（2→2），如实记录「冷却去重未触发」，
    并标注「事件数变化不等于现场更安全」；
  - slice / A/B 的 greedy IoU@0.5 只作诊断，官方 mAP 仍以 `model.val()` 为准。
