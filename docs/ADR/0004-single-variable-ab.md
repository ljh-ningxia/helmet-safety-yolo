# ADR-0004：A/B 实验必须单变量，且同时报告代价

- 状态：已接受（2026-11-26）
- 背景：三项改进（切片推理、时序投票、告警去重）互相影响；如果一次打开
  全部开关再说「效果变好了」，无法归因，也无法解释代价。
- 决策：
  - 每个实验只改 `variable` 指明的一个开关，其余全部冻结并写入
    `frozen_conditions`（权重、图片列表、顺序、seed、imgsz、IoU、设备）；
  - 两组都报告 **Precision / Recall / F1（greedy IoU@0.5）+ 延迟 + 检测框数
    + 告警事件数**，禁止只报有利指标；
  - 每个 JSON 都带 `conclusion_boundary`，说明该结论不能被外推到哪里；
  - 置信度阈值另设一组实验（E2），因为它不是结构改动而是判定门槛。
- 理由：课程评分里创新与价值权重最高，但「价值」必须建立在可归因的
  对照上；同时测代价能防止把「检出框变多」误当成「准确率提升」。
- 后果：
  - E3 时序投票的输入是静态图片序列，报告里明确写出「不是真实连续视频」；
  - E4 事件数下降明确标注「不等于现场更安全」；
  - slice / A/B 的 greedy IoU@0.5 只作诊断，官方 mAP 仍以 `model.val()` 为准。
