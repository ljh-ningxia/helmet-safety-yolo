# ADR-0001：CPU 环境下使用分层子集训练

- 状态：已接受（2026-11-26）
- 背景：开发环境为 12 核 AMD CPU、无 GPU（`nvidia-smi` 不存在，
  `torch.cuda.is_available() == False`）。全量语料 19,745 张，
  1-epoch 速度探测实测 1.25 it/s（batch 8 / imgsz 320）。
- 决策：正式训练取 `train 2,000 / valid 600 / test 600`，12 epochs，
  imgsz 320，batch 16；用「框数分箱 × 是否含违规」分层抽样（固定 seed
  20261126）保证稀有类别比例不失真。
- 理由：
  - 可在约 30–40 分钟内**真实跑完**，而不是停在「脚本写好了但没跑」；
  - 分层抽样比随机抽样更能保护 `no-hardhat` 这一告警目标类；
  - 训练配置、子集大小、耗时与环境指纹全部写进 `train_run.json`，可复核、可对照。
- 后果：
  - 指标是**子集条件下的实测值**，不是全量语料的精度上限；
  - 必须把「CPU 子集」写进模型卡、README 与答辩材料，禁止表述为「全量训练 SOTA」；
  - GPU 环境把 `configs/data/default.yaml` 的 `subset_*` 设为 `null` 即可跑全量，
    结果可与本次形成规模对照。
- 备选方案：
  - 只用 COCO 预训练权重做 zero-shot → 没有 helmet 类别，无法评估；
  - 全量 CPU 训练 → 预计数小时，超出可接受交付窗口；
  - 借用云端 GPU → 需要账号与额外授权，当前环境不可用。
