# 数据集说明与合规

> 本仓库**不分发任何第三方数据集、不内置模型权重**。这是刻意设计：
> 权重与数据必须由本人训练 / 从可追溯来源获取，不能凭空声明。

## 1. 三种数据各自的角色

| 数据 | 用途 | 能否用于性能报告 |
| --- | --- | --- |
| `data/synthetic/`（脚本生成） | 跑通训练 / 评估 / 看板全流程 | ❌ 绝对不能 |
| `data/real/`（本人准备） | 训练 + 验证 + 固定测试集 | ✅ 可以，需注明来源与许可 |
| 公开数据集（自行下载） | 预训练 / 对照 | ✅ 可以，需按原许可引用 |

## 2. 可考虑的公开来源（自行核实许可后再使用）

- **SHWD / Safety Helmet Wearing Dataset**（安全帽佩戴检测，常见类别 `hat` / `person`）
- **Hard Hat Worker Dataset**（含 `helmet` / `head` / `person` 等标注）
- 自建实拍数据：本人拍摄或经项目部授权，标注后固定划分

> 使用前请到项目主页确认许可证（部分为 CC BY / 非商用），在 README 与本文件中如实注明；
> 类别需要映射成本项目的 `0: helmet`、`1: no_helmet` 两类。

## 3. 目录规范

```
data/real/
├── images/
│   ├── train/   *.jpg
│   ├── val/     *.jpg
│   └── test/    *.jpg        ← A/B 只用这里，划分一旦固定不得改动
└── labels/
    ├── train/   *.txt        ← YOLO 格式: cls cx cy w h（归一化）
    ├── val/     *.txt
    └── test/    *.txt        ← 人工逐帧真值，用于 P/R/mAP
```

`src/datasource.py` 会读取同名的 `.txt` 标签；**找不到真值时自动降级为描述性统计，并拒绝输出 P/R/mAP**。

## 4. 测试集纪律（公平对照的前提）

1. `test/` 划分在第一次实验前固定，之后不再改动；
2. A 与 B 必须使用完全相同的测试帧序列；
3. 记录测试集帧数、来源、标注人、标注日期到实验卡；
4. 不允许用测试集调阈值 —— 调参只在 `val/` 上做；
5. 跨数据集 / 跨硬件的结论一律标注「不可外推」。

## 5. 合成数据生成

```bash
python run.py synthetic --count 60 --seed 20261126
```

输出 `images/`、`labels/`、`manifest.json`，manifest 中带
`"warning": "SELFTEST_ONLY - 合成数据，不是真实工地样本"`。
它只用于验证「训练脚本能跑、评估脚本能算、看板能显示」，不产生任何可引用的精度。
