# ADR-0003：数据集与权重的许可隔离

- 状态：已接受（2026-11-26）
- 背景：需要真实工地图片训练，同时要把工程开源到公开 GitHub 仓库。
- 决策：
  - 训练数据选 **Hard Hats Dataset（CC BY 4.0）**：许可在 HF 数据集卡片和
    每个 COCO JSON 的 `licenses` 字段中双重声明，允许使用与再分发，只需署名；
  - 排除 IITU Safety-Helmet Dataset（同为 CC BY 4.0，但 HF 要求登录同意条件
    才能取文件，无法自动化下载），以及 SHWD（图片来自搜索引擎，权属不清、
    数据托管在网盘，不利于可复现）；
  - 基座权重 YOLOv8n 为 **AGPL-3.0**，与本项目 MIT 代码分开声明；
  - 原始图片、解压结果、`.pt` 权重**均不进入 git**，仓库只保留下载脚本、
    SHA256 校验和、统计数据与少量已署名的可视化样本；
  - `NOTICE.md` 集中记录来源、许可、引用格式与商用提示。
- 理由：CC BY 4.0 的署名义务可履行；AGPL 风险必须显式告知，不能靠
  「大家都这么用」默认忽略；大文件不进 git 保证仓库 30 秒可体检。
- 后果：
  - 任何商业部署前必须单独评估 Ultralytics Enterprise 授权，或更换骨干网络；
  - 展示用真实图片必须随附 `NOTICE.md` / `docs/DATASET.md` 中的署名；
  - 复现需要重新下载约 1.07 GB 数据，由断点续传 + 校验和保证一致性。
