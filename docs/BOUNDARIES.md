# 结论边界与未测项

> 这份文件必须和任何性能数字一起展示。写在这里的内容不是免责声明，
> 而是对「这个系统目前能证明什么、不能证明什么」的准确描述。

## 1. 能证明的（MEASURED）

- 在 **Hard Hats Dataset** 的独立 test split 上，用 `model.val()` 实际测得的
  Precision / Recall / mAP@0.5 / mAP@0.5:0.95 —— 见 `docs/EVALUATION.md`。
- 在同一台 CPU 上、同一张图重复推理得到的 P50 / P95 延迟与吞吐 —— 见
  `experiments/results/benchmark.json`（含每一次的原始毫秒数）。
- 三项改进各自的**单变量**效果与代价 —— 见 `experiments/results/ab_*.json`。
- 数据集的类别分布、尺度分布、亮度分布、重复图数量 —— 见 `docs/DATASET.md`。
- 完整链路可复现：命令、seed、环境指纹、git commit 均在 `train_run.json`。

## 2. 不能证明的

### 2.1 现场泛化能力

指标只在这一个公开数据集上测过。上游把原始图片**拉伸**到 640×640，几何比例
已经失真；真实工地的摄像头型号、安装高度、视角、压缩码流都不同。
**没有在客户自有摄像头数据上验证过，因此不能承诺现场精度。**

### 2.2 视频时序稳定性

数据集是离散图片，不是连续监控视频。A/B 中的 `E3_temporal` 用固定顺序排列的
静态图片序列驱动，**只能说明投票机制对输出数量的影响**，不能外推为
「真实视频里告警不再闪烁」。要证明这一点必须有带逐帧标注的连续视频。

### 2.3 极端环境可靠性

夜间、逆光、雨雾、扬尘、安全帽被遮挡、密集人群互相遮挡、工人背对镜头
—— 数据集里没有人工的困难场景标签。评估里的「亮度切片」只是灰度均值代理，
**不是**经过标注确认的夜间/逆光子集。

### 2.4 部署性能

延迟是 **CPU 单图同步推理**，不含视频解码、批处理、网络传输、告警落盘；
没有 TensorRT / ONNX / 量化 / 多线程流水线优化。不能作为边缘设备
（Jetson / 工控机 / 摄像头 NPU）的实时性结论。

### 2.5 业务效果

系统没有接入真实工地的声光报警、工单或处置流程，**没有**事故率下降、
响应时长缩短、人工巡查工时节省等任何业务指标。告警事件数下降只代表
输出收敛，不代表现场更安全。

### 2.6 其他安全要素

只识别「是否佩戴安全帽」两类，不识别帽带是否系好、反光衣、护目镜、
安全带，也不做人员身份识别 / 越界 / 危险区域闯入。

## 3. 已知的数据缺陷

| 缺陷 | 影响 | 缓解 |
|---|---|---|
| 640×640 拉伸缩放 | 长宽比失真，真实部署域偏移 | 迁移前用现场原比例数据重训 / 重评 |
| 类别不平衡 | `no-hardhat`（告警对象）召回天然偏低 | 按类报告指标；上线前做阈值校准或重采样 |
| 图片来自网络图集 | 可能含重复场景、同源图片 | MD5 完全重复检测已做；近似重复未做 |
| 标注未人工复核 | 标签噪声未知 | 只做结构性校验；重要结论需抽样人工核验 |
| 静态图集无时间维度 | 无法评估跟踪 ID 切换 | 明确列为未测项 |

## 4. 合规与伦理

- 数据 CC BY 4.0 需署名；基座权重 AGPL-3.0，商用需单独评估授权。
- 涉及人员影像，生产部署需遵守隐私与工作场所监控法规，最小化留存并做访问控制。
- 输出是**辅助预警**，不应直接作为对人的处分依据：误报干扰现场，漏报有安全风险。

## 5. 下一步优先级

| 级别 | 事项 | 为什么 |
|---|---|---|
| **P0** | 采集带人工逐帧标注的现场连续视频 | 解锁时序稳定性与真实泛化的可验证结论 |
| **P1** | 按现场分布重建独立测试集并重新校准阈值 | 消除上游拉伸与类别不平衡带来的偏差 |
| **P1** | ONNX / TensorRT 导出 + 边缘设备基准 | 让延迟数字具备部署意义 |
| **P2** | 接入工单/声光告警并统计处置闭环 | 从「检测」走向「业务价值」 |
| **P2** | GPU 上用全量 19,745 张重训 | 提升上限，且与子集结果形成规模对照 |
